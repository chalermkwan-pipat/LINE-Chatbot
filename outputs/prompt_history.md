# สรุปคำสั่ง LINE Chat Bot

บอทใช้ Google Apps Script และ Google Sheets แยกข้อมูลตามแชต: แชตส่วนตัวแยกตามผู้ใช้ ส่วนแชตกลุ่มแยกตาม LINE group ID สมาชิกในกลุ่มเดียวกันจึงใช้และดูข้อมูลชุดเดียวกันได้

## เริ่มและจบการทำงานของบอท

- พิมพ์ `hi bot` เพื่อเริ่มการทำงานในแชตปัจจุบัน บอทจะแสดงเมนูหลักแยกเป็นเรื่องนัดหมายและเรื่องเงิน: `1` จัดการนัดหมาย, `2` เช็ควันนี้, `3` เช็คพรุ่งนี้, `4` เมนูเงินเก็บ, `5` ฝากเงิน, `6` ถอนเงิน, `7` balance, `9` ออก
- เมื่อเลือกหัวข้อหลัก บอทจะแสดงเมนูย่อยให้เลือกได้ทั้งพิมพ์เลขหรือชื่อคำสั่ง
- ขณะบอททำงาน ให้ใช้คำสั่งอื่นตามรายการด้านล่าง
- หลังบันทึกสำเร็จ เลือก `1` เพื่อบันทึกต่อ, `2` เพื่อกลับหน้าหลัก หรือ `3` เพื่อออกจากบอท (พิมพ์ `bye bot` ก็ได้)
- พิมพ์ `bye bot` เพื่อจบการทำงาน บอทจะหยุดตอบจนกว่าจะได้รับ `hi bot` อีกครั้ง
- ไม่ต้องใช้ `bye bot` ก็ออกได้: เมนูหลักเลือก `3`, เมนูย่อยเลือก `9`, หลังบันทึกเลือก `3` หรือพิมพ์ `ออก` ได้ทุกขั้นตอน
- หากไม่มีข้อความหรือคำสั่งเกิน 1 นาที ระบบจะปิดการทำงานของบอทในแชตนั้นโดยอัตโนมัติ
- สถานะเริ่ม/จบแยกกันในแต่ละกลุ่มและแชตส่วนตัว

## เริ่มใช้ในกลุ่ม

1. ใน LINE Developers Console เปิด **Messaging API → Allow bot to join group chats**
2. เชิญ LINE Official Account เข้ากลุ่ม
3. วางโค้ดล่าสุดจาก `LineReminderBot.gs` ใน Apps Script แล้วบันทึก
4. รัน `setup` เพื่อสร้างชีต `Savings` และเพิ่มคอลัมน์ที่จำเป็นใน `Users`
5. Deploy เป็นเวอร์ชันใหม่ แล้วพิมพ์ `hi bot` ในแต่ละกลุ่มเพื่อเริ่มใช้บอท

งานนัดหมายและรายการเงินเก็บที่บันทึกในกลุ่มจะมองเห็นได้โดยสมาชิกทุกคนในกลุ่มนั้น ส่วนข้อมูลอีกกลุ่มจะแยกออกจากกัน การแจ้งเตือนรายวันจะส่งกลับไปยังกลุ่มที่เปิดใช้งานไว้

## เริ่มบันทึกโดยเลือกหัวข้อ

พิมพ์ `hi bot` แล้วเลือกหัวข้อหลัก `1` (นัดหมาย) หรือ `2` (เงินเก็บ) จากนั้นเลือกเมนูย่อยและกรอกรายละเอียดตามที่บอทถาม หากรูปแบบไม่ถูกต้องหรือเปลี่ยนใจ ให้พิมพ์ `0` เพื่อออกจากการกรอกและกลับเมนูหัวข้อนั้น หรือใช้ `/cancel` เพื่อกลับเมนูหลัก

### หัวข้อ 1: นัดหมาย

เมนูย่อย: `1` บันทึกนัดหมาย, `2` ดูงานวันนี้, `3` สรุปงานตามวันที่, `4` ลบนัดหมายโดยเลือกหมายเลขจากรายการ, `0` กลับหัวข้อหลัก, `9` ออกจากบอท

ในเมนูหลักเลือก `3` เป็นทางลัดเช็คตารางวันนี้ได้ด้วย
ในเมนูหลักเลือก `4` เป็นทางลัดเช็คตารางวันพรุ่งนี้ได้ด้วย

ในเมนูหลักเลือก `5` เป็นทางลัดเช็คยอดเงินฝาก balance ได้ด้วย

กรอกให้ครบ 4 ช่องในรูปแบบ `YYYY-MM-DD | HH:mm | รายละเอียด | สถานที่` หากไม่มีเวลา หรือสถานที่ ให้เว้นช่องนั้นว่างไว้ แต่คงเครื่องหมาย `|` ให้ครบ

หลังกรอกรายละเอียด บอทจะถามรูปแบบแจ้งเตือน โดยค่าเริ่มต้นคือแจ้งในวันที่ระบุในตาราง: `1` แจ้งในวันที่นัดหมาย หรือ `2` แจ้งล่วงหน้า 1 วัน โดยสรุปแจ้งเตือนรายวันทำงานเวลาเป้าหมาย 08:00 น. ตามเวลาไทย

ตัวอย่าง:

`hi bot` → `1` → `1` → `2026-10-03 | 10:00 | ประชุมทีม | ห้องประชุม A`

ตัวอย่างไม่มีเวลาและสถานที่: `2026-10-03 |  | ประชุมทีม | `

วันใช้รูปแบบ `YYYY-MM-DD`; เวลาใช้ระบบ 24 ชั่วโมง `HH:mm`; สถานที่เป็นข้อมูลเพิ่มเติม

### หัวข้อ 2: เงินเก็บ

เมนูย่อย: `1` บันทึกเงินฝาก, `2` บันทึกเงินถอน, `3` ดูยอด balance, `4` ดูรายละเอียด 15 วันย้อนหลัง, `0` กลับหัวข้อหลัก, `9` ออกจากบอท

หลังบันทึกเงินเก็บ เมนูจะแสดง `1` บันทึกเงินฝาก, `2` บันทึกเงินถอน, `3` ดูยอด balance, `4` ดูรายละเอียด 15 วันย้อนหลัง, `0` กลับหัวข้อหลัก และ `9` ออกจากบอท

ในเมนูหลักเลือก `4` เป็นทางลัดเช็คยอดเงิน balance ได้ด้วย

เมื่อเลือกฝากหรือถอน ให้ส่ง `จำนวนเงิน | หมายเหตุ` ระบบเติมวันที่ปัจจุบันตามเวลาไทยให้อัตโนมัติ เช่น ฝาก `500 | เก็บเงินเดือน` หรือถอน `200 | ใช้จ่าย`

ตัวอย่าง:

`hi bot` → `2` → `1` → `500 | เก็บเงินเดือน`

จำนวนเงินต้องมากกว่า 0 และรองรับทศนิยมไม่เกิน 2 ตำแหน่ง

ยอดคงเหลือคำนวณจากรายการในชีต `Savings` เท่านั้น โดยนำยอดฝากสะสมลบยอดถอนสะสม

## คำสั่งอื่น

| คำสั่ง | ตัวอย่าง | การทำงาน |
|---|---|---|
| `hi bot` | `hi bot` | เริ่มทำงานในแชตปัจจุบัน |
| `bye bot` | `bye bot` | จบการทำงานในแชตปัจจุบัน |
| `/help` | `/help` | แสดงรายการคำสั่งขณะบอททำงาน |
| `ยอดเงินเก็บ` หรือ `/balance` | `ยอดเงินเก็บ` | แสดงยอดฝากสะสม ยอดถอนสะสม และยอดคงเหลือของแชตปัจจุบัน |
| `เริ่ม` | `เริ่ม` | เปิดรับการแจ้งเตือนในแชตปัจจุบัน |
| `วันนี้` | `วันนี้` | ดูนัดหมายที่ยังใช้งานอยู่ของวันนี้ |
| `สรุปงาน YYYY-MM-DD` | `สรุปงาน 2026-10-03` | ดูนัดหมายที่ยังใช้งานอยู่ในวันที่กำหนด |
| `ลบงาน <รหัสงาน>` | `ลบงาน a1b2c3d4` | ลบนัดหมายในแชตปัจจุบัน โดยเปลี่ยนสถานะเป็น `DELETED` |
| `หยุดแจ้งเตือน` | `หยุดแจ้งเตือน` | ปิดสรุปรายวันของแชตปัจจุบัน |
| `เริ่มแจ้งเตือน` | `เริ่มแจ้งเตือน` | เปิดสรุปรายวันของแชตปัจจุบัน |
| เพิ่มนัดหมายแบบคำสั่งเดียว | `เพิ่มงาน | 2026-10-03 | 10:00 | ประชุมทีม | ห้องประชุม A` | บันทึกนัดหมายโดยไม่ผ่านการเลือกหัวข้อ |

## ชีตที่ใช้

- `Tasks`: นัดหมาย; ค่า `scopeKey` ระบุกลุ่ม/แชต และ `รูปแบบเตือน` เก็บตัวเลือกแจ้งล่วงหน้าหรือแจ้งในวันที่นัด
- `Savings`: รายการเงินเก็บ; ค่า `userId` ใช้ owner key แบบเดียวกัน
- `Users`: owner key สถานะการแจ้งเตือน วันสมัคร ขั้นตอนบันทึก target ID ชนิดแชต สถานะเปิด/ปิดบอท เวลากิจกรรมล่าสุด และนัดหมายที่รอเลือกรูปแบบแจ้งเตือน

Trigger จะส่งสรุปนัดหมายที่ยังใช้งานอยู่ของวันนี้ เวลาเป้าหมาย 08:00 น. ตาม `Asia/Bangkok`; Apps Script อาจเริ่มทำงานคลาดเคลื่อนเล็กน้อย
