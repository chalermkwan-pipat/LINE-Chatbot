# LINE Chatbot

บอท LINE สำหรับจัดการนัดหมาย เงินเก็บ และเงินผ่อน โดยใช้ Google Apps Script เชื่อมต่อกับ Google Sheets รองรับแชตส่วนตัวและแชตกลุ่ม พร้อมส่งการแจ้งเตือนนัดหมายอัตโนมัติ

## ความสามารถหลัก

- **นัดหมาย:** บันทึกงาน เลือกวันและเวลา เลือกการแจ้งเตือน สรุปงานตามวันที่ และลบนัดหมาย
- **เงินเก็บ:** บันทึกฝาก/ถอน ดูยอดคงเหลือ และดูประวัติย้อนหลัง 15 วัน
- **เงินผ่อน:** เก็บข้อมูลสัญญา แยกเงินต้นกับดอกเบี้ย ดูยอดคงค้าง และดูประวัติย้อนหลัง 16 เดือน
- **สิทธิ์ใช้งาน:** ผู้ดูแลกำหนดสิทธิ์ตามหัวข้อให้ทั้งกลุ่มหรือสมาชิกได้จากแชตส่วนตัว
- **แชตกลุ่ม:** ข้อมูลแยกตามแชต กลุ่มหนึ่งจึงไม่เห็นข้อมูลของอีกกลุ่มโดยอัตโนมัติ

## เริ่มต้นใช้งาน

1. สร้าง Google Sheet สำหรับเก็บข้อมูล แล้วเปิด **Extensions → Apps Script**
2. คัดลอก `outputs/LineReminderBot.gs` ไปวางใน Apps Script แล้วบันทึก
3. ตั้งค่า Script Properties ใน **Project Settings**:
   - `LINE_CHANNEL_ACCESS_TOKEN` — Channel access token จาก LINE Developers Console
   - `WEBHOOK_KEY` — คีย์ลับสำหรับตรวจสอบ webhook
   - `BOT_ADMIN_USER_IDS` — LINE user ID ของผู้ดูแล คั่นหลาย ID ด้วยเครื่องหมายจุลภาค
4. รัน `setup()` หนึ่งครั้งและอนุญาตสิทธิ์ที่ Apps Script ขอ
5. Deploy เป็น **Web app** โดยให้ทำงานในสิทธิ์เจ้าของชีต แล้วคัดลอก URL
6. ตั้ง Webhook URL ใน LINE Developers Console เป็น `<Web-app-URL>?key=<WEBHOOK_KEY>` แล้วเปิดใช้ webhook และกด Verify
7. หากจะใช้ในกลุ่ม ให้เปิด **Allow bot to join group chats** แล้วเชิญ LINE Official Account เข้ากลุ่ม

`setup()` สร้างชีตที่จำเป็นและตั้ง trigger สำหรับแจ้งเตือนกับคำนวณดอกเบี้ยรายวันเวลา 06:00 น. ตาม `Asia/Bangkok` และ trigger ล้าง session ที่ไม่มีการใช้งานทุก 1 นาที

## คำสั่ง

พิมพ์คำสั่งที่รู้จักเพื่อเริ่มใช้งานได้ทันที หรือพิมพ์ `hi bot` เพื่อแสดงเมนูหลัก

| คำสั่ง | การทำงาน |
|---|---|
| `C1` | เมนูนัดหมาย |
| `C2` | บันทึกนัดหมาย |
| `C3` | สรุปงานตามวันที่ |
| `M1` | เมนูเงินเก็บ |
| `M2` | ฝากเงิน |
| `M3` | ถอนเงิน |
| `M4` | ดูยอด balance |
| `L1` | เมนูเงินผ่อน |
| `L2` | ดูยอดเงินผ่อนคงค้าง |
| `A1` | กำหนดสิทธิ์ (ผู้ดูแลในแชตส่วนตัวเท่านั้น) |
| `X` | ออกจากการใช้งานบอท |
| `/help` | ดูคำสั่งที่ใช้งานได้ |
| `/cancel` | ยกเลิกขั้นตอนปัจจุบัน |

ตัวอักษรคำสั่งภาษาอังกฤษพิมพ์เล็กหรือใหญ่ก็ได้ Session จะหมดอายุเมื่อไม่มีการใช้งานเกิน 1 นาที

## โครงสร้างข้อมูล

Apps Script สร้างชีตต่อไปนี้ใน Google Sheet:

- `Tasks` — นัดหมายและรูปแบบการแจ้งเตือน
- `Savings` — ฝาก/ถอนเงิน
- `Installments` — สัญญาและรายการชำระเงินต้น/ดอกเบี้ย
- `Users` — ข้อมูลแชต การแจ้งเตือน และสถานะการใช้งาน
- `Permissions` — สิทธิ์ตามกลุ่มและสมาชิก

## ความปลอดภัย

อย่า commit ค่า Channel access token, `WEBHOOK_KEY` หรือข้อมูลส่วนตัวลง repository ให้เก็บไว้ใน Script Properties เท่านั้น ข้อมูลที่บันทึกในกลุ่มจะมองเห็นได้โดยสมาชิกที่ใช้บอทในกลุ่มนั้น

หลังแก้โค้ด ต้องสร้าง Apps Script deployment เวอร์ชันใหม่เพื่อให้ LINE เรียกใช้การเปลี่ยนแปลงล่าสุด
